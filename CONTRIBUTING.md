# Contributing

Thanks for helping make Snowflake Method better. You can help in two ways.

- [Bug report](https://github.com/ZzPoLariszZ/obsidian-snowflake-method/issues/new?template=bug_report.yml): something isn't working.
- [Feature request](https://github.com/ZzPoLariszZ/obsidian-snowflake-method/issues/new?template=feature_request.yml): you have a new idea.

Before you open an issue, update to the latest version and search the [existing issues](https://github.com/ZzPoLariszZ/obsidian-snowflake-method/issues?q=is%3Aissue). Questions go to [Q&A](https://github.com/ZzPoLariszZ/obsidian-snowflake-method/discussions/categories/q-a). English or Chinese are both fine.

Pull requests aren't accepted for now. Open an issue instead.

###### 简体中文

# 参与贡献

感谢你帮助改进雪花写作法。你可以通过两种方式参与。

- [问题反馈](https://github.com/ZzPoLariszZ/obsidian-snowflake-method/issues/new?template=bug_report.yml)：某个功能不正常。
- [功能建议](https://github.com/ZzPoLariszZ/obsidian-snowflake-method/issues/new?template=feature_request.yml)：你有新的想法。

提交 issue 之前，请先更新到最新版本，并搜索[已有的 issue](https://github.com/ZzPoLariszZ/obsidian-snowflake-method/issues?q=is%3Aissue)。使用上的疑问请到 [Q&A](https://github.com/ZzPoLariszZ/obsidian-snowflake-method/discussions/categories/q-a) 提问。中文或英文都可以。

目前不接受 Pull Request，请改为提交 issue。
